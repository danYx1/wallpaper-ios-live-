# LiveWallpaperApp

Приложение для iPad/iPhone: создаёт Live Photo из короткого видео
и помогает быстро открыть его в «Фото», чтобы поставить на экран блокировки.

Никаких приватных API и джейлбрейка — работает на любом iPadOS/iOS
через официальный PhotoKit.

## Вариант A — собрать .ipa через GitHub Actions (без своего Mac)

В репозитории уже лежит `project.yml` (XcodeGen) и
`.github/workflows/build-ipa.yml`. Раннер GitHub сам поднимет macOS,
соберёт проект и отдаст `.ipa` файлом-артефактом.

1. Создайте новый репозиторий на GitHub и загрузите туда содержимое
   этой папки целиком (сохраняя структуру, включая скрытую папку `.github`).
2. Во вкладке **Actions** откройте workflow **Build IPA** → **Run workflow**.
3. Дождитесь зелёной галочки (обычно 3–6 минут).
4. Откройте завершённый запуск → в самом низу раздел **Artifacts** →
   скачайте `LiveWallpaperApp-ipa.zip`, внутри — `LiveWallpaperApp.ipa`.

**Важный момент про подпись.** Этот `.ipa` собран БЕЗ подписи
(`CODE_SIGNING_ALLOWED=NO`) — GitHub-раннер не имеет и не должен иметь
ваш Apple ID или сертификат. Установить такой файл напрямую через
обычный "Установить .ipa" нельзя — его нужно подписать уже на своей
стороне одним из способов:

- **AltStore / SideStore** — при установке через них ipa переподписывается
  вашим бесплатным Apple ID автоматически.
- **Sideloadly** — то же самое, с компьютера (Windows/Mac), через кабель.

Если хотите сразу подписанный ipa — это возможно, но тогда придётся
положить в секреты репозитория (GitHub Secrets) свой сертификат разработчика
и provisioning profile; могу собрать такой workflow отдельно, если скажете,
что у вас есть платный Apple Developer аккаунт ($99/год).

## Вариант B — собрать локально в Xcode

1. Откройте Xcode → **File → New → Project → iOS → App**
   - Interface: **SwiftUI**
   - Language: **Swift**
   - Minimum deployment target: iOS 17+
2. Удалите автосозданный `ContentView.swift` из проекта.
3. Перетащите в проект все `.swift` файлы из папки `LiveWallpaperApp/`.
4. Откройте **Info** проекта (вкладка Info в настройках таргета) и добавьте ключи:

   | Key | Value |
   |---|---|
   | `NSPhotoLibraryUsageDescription` | Нужно, чтобы показать ваши живые фото |
   | `NSPhotoLibraryAddUsageDescription` | Нужно, чтобы сохранить созданное живое фото |

5. Подключите iPad к Mac (Live Photo на симуляторе проигрываются не всегда корректно).
6. Signing & Capabilities → выберите свою Apple ID команду (бесплатного
   Apple ID достаточно для запуска на своём устройстве).
7. Run (⌘R).

## Структура

- `LivePhotoGalleryView.swift` — сетка существующих Live Photo из вашей библиотеки
- `LivePhotoDetailView.swift` — предпросмотр с анимацией + кнопка «Открыть в Фото»
- `LivePhotoCreatorView.swift` — выбор видео через PhotosPicker
- `LivePhotoMaker.swift` — сборка JPEG+MOV с общим `assetIdentifier`, который iOS распознаёт как Live Photo
- `PhotoLibraryService.swift` — чтение/запись в библиотеку через PhotoKit

## Важно про "обои"

iOS/iPadOS не разрешает сторонним приложениям напрямую менять системные
обои — это всегда ручное действие пользователя (Поделиться → «Использовать
как обои» в приложении Фото, либо долгое нажатие на фото). Приложение
доводит вас до последнего шага максимально быстро, но сам системный
диалог установки обоев принадлежит Apple.
